# Sentinel (哨兵)

Sentinel 是一款专为极客桌面打造的轻量化、实时流式语音转文本（STT）前端工具。

在当前版本中，Sentinel 专注于提供极致的**“实时字幕与动态纠错”**体验。它就像一个蛰伏在系统后台的数字哨兵，静默捕获物理环境的音频流，并将其极速管道化至后端的 Qwen3-ASR GGUF 量化模型。

它不仅是一个简单的听写工具，更是一个动态的文本解析器。Sentinel 打破了传统语音输入“录音-等待-输出”的迟滞感，在文字实时流式上屏的同时，还能根据上下文进行动态的语义回退与精准修正。最终呈现在屏幕上的，是如同心流般平滑、无需二次键盘干预的高质量字幕。

轻量、敏捷、准确。它是你物理声音与数字世界之间，最可靠的连接通道。

## ✨ 核心特性

*   **实时流式上屏**：打破迟滞，音频输入极速可视化。
*   **动态语义纠错**：接入 Qwen3-ASR 模型，支持流式输出过程中的上下文自我修正。
*   **轻量级静默运行**：专注核心听觉感知，提供无干扰的悬浮字幕体验。

## 🚀 快速开始

1. 确保已安装 Python 环境。
2. 克隆本仓库到本地：
   ```bash
   git clone [https://github.com/llrrdb/Sentinel.git](https://github.com/llrrdb/Sentinel.git)

```

3. 激活虚拟环境（建议）并运行主程序：
```bash
python main.py

```



*(注：后端 Qwen3-ASR GGUF 模型的配置方法请参考内部设置说明。)*
